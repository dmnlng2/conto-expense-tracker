# Conto — Expense Tracker

Conto è una web app per registrare le spese personali e consultare un riepilogo mensile.

[Prova la demo](https://dmnlng2.github.io/conto-expense-tracker/)

- Aggiungi, modifica ed elimina le spese.
- Filtra i movimenti per mese e categoria.
- Consulta il totale mensile, la spesa media e la ripartizione per categoria.

Realizzato con HTML, CSS e JavaScript. Le spese vengono salvate nel browser.
